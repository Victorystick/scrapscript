# RFCs

Proposals for changes to the language, written before the change is made
(AGENTS.md: discuss design changes before implementing them). SPEC.md stays
the source of truth: an accepted RFC is folded into it, and the RFC remains
as the record of why.

- One file per proposal, `NNNN-short-name.md`, numbered in order.
- Each starts with a status line: draft, accepted, rejected or withdrawn.
- Cover the motivation, the proposed design, the arguments against and the
  alternatives, and what would change in SPEC.md.
